# Python Automation & Utility Scripts 🚀

A structured collection of lightweight Python automation scripts designed to eliminate repetitive manual tasks, organize file systems, and boost day-to-day developer productivity.

---

## 🛠️ Included Scripts

### 1. Secure Password Generator (password_generator.py)
* Generates strong, cryptographically secure random passwords.
* Combines uppercase, lowercase, numbers, and special punctuation characters.
* Configurable password length.

### 2. Smart File Organizer (file_organizer.py)
* Automatically categorizes and moves files in a target directory into organized folders based on their extensions (Documents, Images, Archives, Scripts, Others).
* Prevents cluttered desktop/download directories.
